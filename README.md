# Лабораторная работа №15

## Система управления библиотечным фондом (Вариант №3)

Консольное объектно-ориентированное приложение на языке Java для автоматизации процессов учёта, поиска, выдачи и возврата библиотечных материалов с расчётом штрафов за просрочку и файловым хранением данных.

---

## 📌 Назначение приложения

Приложение предназначено для решения следующих задач библиотечного фонда:
- **Учёт разнородных материалов**: поддержка печатных книг (`PrintedBook`) и электронных изданий (`ElectronicBook`).
- **Регистрация читателей**: ведение базы данных читателей с индивидуальными лимитами на единовременную выдачу печатных книг.
- **Выдача материалов**: контроль наличия свободных копий, проверка действующих ограничений читателя (лимит книг, отсутствие просроченных задолженностей).
- **Возврат материалов и расчёт штрафов**: начисление штрафа за каждый день просрочки для печатных изданий (электронные ресурсы штрафами не облагаются).
- **Поиск и фильтрация**: гибкий поиск по названию, автору, шифру и признаку доступности экземпляров.
- **Файловая персистентность**: долговременное хранение состояния библиотеки в файлах формата CSV/TXT и автоматическое восстановление при запуске.

---

## 🚀 Основные возможности

1. **Регистрация библиотечных материалов**:
   - Печатные книги: учёт количества страниц, расположения на полке, индивидуальной ставки штрафа за день и стандартного срока выдачи.
   - Электронные издания: учёт формата (PDF, EPUB, FB2 и др.), размера файла в МБ и ссылки для скачивания/онлайн-доступа.
2. **Многокритериальный поиск (перегрузка методов)**:
   - `searchMaterials(query)` — поиск по ключевой фразе;
   - `searchMaterials(query, onlyAvailable)` — поиск с фильтром только доступных для выдачи экземпляров;
   - `searchMaterials(query, typeFilter, onlyAvailable)` — поиск с одновременной фильтрацией по категории материала.
3. **Ограничения на выдачу (бизнес-логика Варианта 3)**:
   - Невозможно выдать материал, если все его копии уже заняты (`MaterialNotAvailableException`).
   - Невозможно выдать печатную книгу читателю, достигшему своего лимита по количеству активных книг (`BorrowLimitExceededException`).
   - Блокировка выдачи любых материалов читателю при наличии у него просроченных задолженностей до момента их погашения.
4. **Расчёт штрафов за просрочку**:
   - Для печатных книг сумма штрафа рассчитывается по формуле: `штраф = дни_просрочки * ставка_в_день`.
   - Для электронных ресурсов штраф равен `0.00 руб.` (полиморфное поведение).
5. **Защита целостности фонда**:
   - Запрещено удалять/списывать материалы, которые в данный момент находятся на руках у читателей.
6. **Сохранение и восстановление данных**:
   - Каталог `data/`: `materials.txt`, `readers.txt`, `borrows.txt`.
   - Использование потоков ввода-вывода Java (`BufferedReader`, `BufferedWriter`, `StandardCharsets.UTF_8`) с блоками `try-catch-finally`.
7. **Интерактивное консольное меню**:
   - 14 пунктов меню, подробные подсказки, защита от некорректного пользовательского ввода (`NumberFormatException`, пустые строки).
8. **Встроенный автоматический тестовый набор**:
   - Класс `com.library.test.LibraryTestSuite` осуществляет 22 автоматические проверки всех сценариев и исключений.

## 🏛 Архитектура проекта

Проект спроектирован с соблюдением принципов объектно-ориентированного программирования и **SOLID**:

```
src/
└── com/
    └── library/
        ├── Main.java                        // Точка входа в приложение
        ├── exception/                       // Собственные классы исключений
        │   ├── LibraryException.java        // Базовое проверяемое исключение
        │   ├── MaterialNotFoundException.java
        │   ├── MaterialNotAvailableException.java
        │   ├── BorrowLimitExceededException.java
        │   ├── ValidationException.java
        │   └── StorageException.java
        ├── model/                           // Объектная модель предметной области
        │   ├── Identifiable.java            // Обобщённый интерфейс с ID
        │   ├── Borrowable.java              // Интерфейс операций выдачи/возврата
        │   ├── LibraryMaterial.java         // Абстрактный базовый класс материалов
        │   ├── PrintedBook.java             // Печатная книга
        │   ├── ElectronicBook.java          // Электронное издание
        │   ├── Reader.java                  // Читатель
        │   └── BorrowRecord.java            // Запись о выдаче материала
        ├── repository/                      // Слой хранения (Generics)
        │   ├── Repository.java              // Обобщённый интерфейс репозитория
        │   └── InMemoryRepository.java      // Обобщённая реализация на LinkedHashMap
        ├── service/                         // Слой бизнес-логики
        │   ├── LibraryService.java          // Контракт сервиса библиотеки
        │   └── LibraryServiceImpl.java      // Реализация правил выдачи и штрафов
        ├── storage/                         // Файловый ввод-вывод
        │   └── FileStorageManager.java      // Сохранение и загрузка данных из файлов
        ├── ui/                              // Пользовательский интерфейс
        │   └── ConsoleMenu.java             // Консольное меню управления
        ├── util/                            // Обобщённые алгоритмы
        │   └── GenericUtils.java            // Обобщённые методы filter, map, findFirst
        └── test/                            // Тестирование
            └── LibraryTestSuite.java        // Автоматизированный тестовый набор
```

### Соответствие требованиям лабораторной работы:
- **Инкапсуляция**: поля классов закрыты (`private`), доступ и модификация осуществляются через геттеры и сеттеры с валидацией инвариантов сущностей.
- **Наследование и Абстракция**: абстрактный класс `LibraryMaterial` объединяет общее состояние и объявляет абстрактные методы `calculateFine(int days)`, `getMaterialType()`, `getDefaultLoanDays()`, которые переопределяются в производных классах `PrintedBook` и `ElectronicBook`.
- **Полиморфизм**:
  - *Перегрузка (overloading)*: методы поиска `searchMaterials(...)`, выдачи `borrowMaterial(...)` и расчёта штрафов `calculateFine(...)`.
  - *Переопределение (overriding)*: полиморфное вычисление штрафа `calculateFine()` в производных классах с вызовом через ссылку типа `LibraryMaterial`.
- **Интерфейсы**: интерфейсы `Borrowable` и `Identifiable<ID>`.
- **Коллекции и Обобщённые типы (Generics)**:
  - Использование `List<T>`, `Map<K, V>`, `Optional<T>`.
  - Собственный обобщённый класс: `InMemoryRepository<T extends Identifiable<ID>, ID>`.
  - Собственные обобщённые методы: `GenericUtils.filter(...)`, `GenericUtils.map(...)`, `GenericUtils.findFirst(...)`.
- **Обработка исключений**: использование конструкций `try`, `catch`, `finally`, `throw`, `throws` и иерархии исключений с базовым классом `LibraryException`.
- **Файловый ввод-вывод**: запись и чтение файлов в каталоге `data/` с помощью `BufferedReader` и `BufferedWriter`.

## 🛠 Инструкция по сборке и запуску

### Предварительные требования
- Установленный Java Development Kit (JDK) версии 17 или выше (протестировано на JDK 26).
- Git для управления версиями.

### 1. Компиляция проекта через терминал

Из корневого каталога проекта выполните команду компиляции исходных файлов:

```bash
javac -encoding UTF-8 -d out -sourcepath src src/com/library/Main.java
```

### 2. Запуск приложения

```bash
java -Dfile.encoding=UTF-8 -cp out com.library.Main
```

*(На ОС Windows в PowerShell или cmd предварительно можно переключить кодовую страницу на UTF-8 командой `chcp 65001`).*

### 3. Запуск встроенных автоматических тестов

Тесты можно запустить как из пункта **13** консольного меню, так и напрямую через терминал:

```bash
java -Dfile.encoding=UTF-8 -cp out com.library.test.LibraryTestSuite
```
